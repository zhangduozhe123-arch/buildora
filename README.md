# Buildora - AI 建站平台

一个基于 AI 的网站建设平台，帮助用户快速创建和管理网站。

## 功能模块

### 核心功能
- **仪表盘** - 项目概览、最近活动、快速操作
- **客户管理** - 客户 CRUD、搜索、状态管理
- **产品与服务** - 产品 CRUD、计费方式管理
- **项目管理** - 项目卡片、状态筛选（全部/已发布/草稿）
- **数据分析** - KPI 卡片、流量趋势图、项目分布图

### AI 功能
- **AI 建站编辑器** - 可视化编辑、组件库、AI 生成素材
- **落地页预览** - 桌面/移动端预览、Hero 区域展示
- **AI 可读站点** - 让网站被 AI 搜索引擎发现

### 付费功能（已暂时关闭）
- 支付网关
- 品牌定制（白标）
- 自定义域名
- 自定义邮件

### 其他功能
- 推广获客（Leads 管理）
- 第三方连接集成
- 设置（账户、订阅、API 密钥、数据库配置）

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **数据库**: Supabase (PostgreSQL)
- **部署**: 本地开发服务器

## 数据库

使用 Supabase 作为后端数据库，支持实时数据同步。包含以下数据表：
- `clients` - 客户信息
- `products` - 产品与服务
- `projects` - 建站项目
- `activities` - 活动记录

## 快速开始

1. 克隆仓库
2. 用浏览器打开 `index.html` 或启动本地服务器
3. 在设置页面配置 Supabase 数据库连接
4. 首次使用需运行 `supabase-schema.sql` 建表脚本
